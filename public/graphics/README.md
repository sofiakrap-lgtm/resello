# Grafiikat (logot, ikonit, kuvitukset)

Pudota tähän kansioon logot, SVG-grafiikat, kuvitukset ja muut vektori- tai
graafiset elementit. Tiedostoihin viitataan polulla `/graphics/<tiedostonimi>`.

## Ohjeet

- **Muoto:** SVG on paras logoille ja ikoneille (terävä joka koossa, pieni
  tiedosto). PNG jos tarvitset läpinäkyvyyttä rasterikuvassa.
- **Logo:** esim. `resello-logo.svg`. Kerro minulle, kun se on täällä, niin
  vaihdan tekstilogon tilalle sivun ylä- ja alatunnisteessa.
- **Lisääminen GitHubissa:** avaa tämä kansio → **Add file → Upload files**.

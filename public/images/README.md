# Kuvat (valokuvat)

Pudota valokuvat tähän kansioon. Tiedostoihin viitataan sivulla polulla
`/images/<tiedostonimi>`.

## Sivu etsii näitä tiedostoja automaattisesti

Jos lisäät tiedoston tällä nimellä, se ilmestyy sivulle heti — ilman
koodimuutoksia. Jos tiedostoa ei ole, näkyy paikanpitäjä.

| Tiedostonimi           | Mihin näkyy                        | Suositeltu koko / muoto      |
| ---------------------- | ---------------------------------- | ---------------------------- |
| `hero.webp`            | Heron oikea palsta (koko korkeus)  | 2400×1500 (16:10), WebP      |
| `app-screenshot.webp`  | Ratkaisu-osion puhelinnäkymä       | 1080×2280 (pysty), WebP      |

## Ohjeet

- **Muoto:** WebP tai JPG valokuville. WebP on pienin samalla laadulla.
- **Tarkkuus:** tallenna 2× näyttökoossa terävyyden vuoksi.
- **Koko:** pidä tiedosto mielellään alle 400 kt.
- **Lisääminen GitHubissa:** avaa tämä kansio → **Add file → Upload files**.

## Muut kuvat

Voit lisätä tänne muitakin kuvia ja viitata niihin koodissa, esim.
`/images/tiimi.webp`. Kerro minulle, mihin osioon haluat ne, niin kytken ne.
